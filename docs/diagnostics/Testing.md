# Проверки диагностики Smart Routing

## Автономные регрессионные тесты

Тесты создают временные mock-команды `ssh`, `nslookup`, `ipset`, `ip`, `iptables`. Реальный роутер не подключается, команды изменения runtime не вызываются.

Из корня репозитория:

```bash
pytest -q tests/diagnostics/test_maxvpn_smart_routing_ipv4_diagnostic.py
```

Покрытие включает:

- аудит сразу нескольких доменов и несколько A-записей одного домена;
- ошибку DNS-резолвинга и ненулевой код завершения;
- IP, отсутствующий в `MAXVPN_DIRECT`;
- source-aware lookup только при адресе клиента внутри сети `br-lan`;
- раннее отклонение некорректного доменного имени без SSH;
- сохранение `.log` и `.md` для аудита нескольких доменов.

## Реальная проверка нескольких доменов

После прохождения автономных тестов выполнить read-only аудит известных DIRECT-доменов:

```bash
bash scripts/run_maxvpn_smart_routing_report.sh mts.ru rzd.ru wialonlocal.online
```

Эта команда использует DNS и runtime-состояние текущего роутера. Если она обнаружит IP, отсутствующий в `MAXVPN_DIRECT`, или другой `FAIL`, ничего вручную не добавлять и не удалять: приложить полный вывод и свежий `.log`, чтобы сверить его с DNS-worker.

IPv6 остаётся вне области работ, так как провайдер не предоставляет IPv6. Проверки не меняют маршруты, firewall, IP-set, VPN-режим или счётчики.
