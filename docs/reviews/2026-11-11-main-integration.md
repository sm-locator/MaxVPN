## Исправления по результатам обзора

1. **P1 — запуск VPN без авторизации.** В `POST /api/v1/vpn/start`
   добавлена проверка пользователя. Регрессионный тест проверяет ответ `401`
   и отсутствие вызова сервиса запуска; существующие тесты сохраняют проверку
   авторизованного запуска.
2. **P2 — неверная отметка применения правил.** Appliance теперь вычисляет
   отметку из того же снимка правил, который передаёт в runtime. Изменение
   правила во время применения остаётся ожидающим и обнаруживается следующим
   восстановлением. Проверяются изменение цели, включение/отключение,
   добавление и удаление правила.
3. **P2 — ошибки запросов в интерфейсе.** Опрос диагностики и изменение правил
   завершают состояние ожидания и показывают ошибку пользователю.
4. **Проверки frontend.** В CI добавлен отдельный запуск тестов, линтера и
   production-сборки React-приложения.

- Чистая установка frontend через `npm ci`, 67 тестов, линтер и production-сборка.
- Проверка стиля изменённых Python API и нового регрессионного теста.

Новые проверки backend покрывают авторизацию запуска и согласованность снимка
правил при параллельном редактировании. Тесты frontend проверяют существующие
функции и API; отдельный компонентный стенд для новых обработчиков не добавлялся.
Результаты удалённого CI приведены в PR.

Формат исходников проверяется через `git diff --check` с исключением вложенного
unified-патча sing-box: его обязательные пробелы контекста вызывают предупреждения
при проверке внешнего diff. Сам патч успешно разбирается `git apply --numstat`.
